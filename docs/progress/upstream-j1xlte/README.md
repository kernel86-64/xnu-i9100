# Previous J1/HD2 source snapshot

These documents, source-side compatibility headers and static checker are retained
from the previous branch tip [eca5450522a2](https://github.com/kernel86-64/xnu-i9100/tree/eca5450522a27e07eb8ccda376bdc764b8063b23).
They describe the older J1/HD2 snapshot and its nested `xnu/` layout. The old
manifest and checker apply to that revision, not the current GT-I9100 tree.

The current kernel sources are at the repository root. Use the
[current README](../../../README.md), `SOURCE_MANIFEST.json` and `port-tests/`
for current build and checks. The original license notice remains at
[LICENSE-NOTICE.md](../../../LICENSE-NOTICE.md).

Original supplemental files are preserved byte-for-byte. This folder is an
archive, not a build include directory or a verification of the current port.
