# GT-I9100 development notes — MALI33

Only international Exynos4210 GT-I9100 is targeted. CPU1, audio, radios,
suspend/resume, separate recovery and powered-off charging are not implemented
or verified. Rootfs writes use volatile RAM COW. Touch uses the retained polling
and instrumented IRQ/preemption path; the display remains CPU rendered.

## GPU and diagnostics

Mali GP/4PP/5MMU power/clock and a private 64 KiB noncacheable arena are
implemented for one boot-time self-test. GPU27 clears and GPU28 triangles passed
on the phone. GPU30 also passed both opaque PP0 texture patterns and same-VA
update, then failed the first blend: `E-18 J7 X2 A1 B8080:ff881020`.
GPU31 fixes PP RGBA clear packing versus BGRA writeback and makes clear job 2
use an asymmetric color so the original blind spot is covered earlier.

HUD32 keeps three bottom rows (16 pixels each): GPU at y752, BAT at y768,
LIVE IRQ at y784. Only a GPU failure adds details at y736. No Home/touch,
COPY/GAP/SD/cache, SpringBoard/backboard/signal/abort or top-right square is
drawn during normal UI operation. Observation collection and input/trace paths
remain enabled. The same rows are drawn after a present and by the timer;
LIVE IRQ is no longer overwritten by the old SD row. `i9100perf=0` hides them.

Expected GPU31 test success in the compact HUD32 layout:

```text
GPU S11 E0 R1 C133 P4096 J16 X12 Af M0 G1
```

`Af` confirms tested textured cores; P4096 is the complete tested pixel count.
On failure the extra GPU row shows offset/observed word, GP/PP IRQ, T/V counts
and detected PP mask. Frequency
can differ up to 160 MHz. J1/2 clear, J3/4 triangles, J5–16 three texture jobs
per PP (opaque, update, blend). E-18 is a texture/blend output mismatch; B gives
offset and observed word. G0 after an earlier failure means the full test did
not finish, and by itself does not prove guard corruption. MMU faults M and
restore R are separate; R2 means quiescence/restore could not be confirmed.

No live framebuffer or IOSurface is a GPU DMA target. GPU IRQ masks remain zero;
polling is bounded and STOP_BUS acknowledgement precedes power-off. Private
pages stay pinned. No iOS accelerator user client, general shader compiler,
GLES/EAGL backend or accelerated SpringBoard is provided. Retain software iOS
rendering until a real userspace backend exists.

## Boot switches and failures

Home, power and the GPU test default to enabled. `i9100gpu=0` skips only the
GPU test, `i9100home=0` skips Home, `i9100power=0` skips charger control and
`i9100perf=0` hides diagnostics. Use the loader's `--extra-cmdline` for overrides.
Keep `I9100_LOCK_TRACE=1`: turning collection off lost touch on the phone;
PERF22 optimizes lookup while retaining the working control path.

Reported complete freezes stopped after the cache fixes. SpringBoard still
sometimes exits, including QuartzCore slab magic assertions. RM29 ref/mod,
COPY25 partial-page copy and ARGS26 syscall argument fixes are retained; host
reproduction of these defects does not identify the writer in a device photo.
Capture GPU/GIRQ and any panic/SLAB/MAGIC lines with the exact kernel UUID and
matching `mach_kernel.sys`/`assym.s`; never symbolize a prior photo using a newer
kernel. A stopped display marker or interrupted PC alone does not identify cause.

Battery CHG1 is sampled charging status; USB1 is cable presence. R0 is normal
control; negative reasons: -1 I/O/invalid telemetry, -2 unknown revision,
-3 temperature, -4 full, -5 timeout, -6 absent battery, -7 offline.
Revision14 uses MAX8922; main/sub controllers follow the EUR board revision.
A full charge cycle is unverified. A stopped CPU cannot run software thermal
supervision. Home's 52-byte queue fix remains enabled; its action needs physical
confirmation separately from touch.

## Hardware constraints

UART2 is `0x13820000`. Accessing clock-gated UART0 `0x13800000` can hang AXI.
HSMMC2 is `0x12530000`; MCT `0x10050000`, 24 MHz, IRQ89; GIC CPU/distributor
`0x10480000`/`0x10490000`; ADC `0x13910000`; Mali `0x13000000`.
RAM is Normal WBWA. Reserved scanout physical `0x43e00000` and all its aliases
are Normal noncacheable. Preserve PTE cleaning/barriers; do not guess SD byte
repairs, fabricate HFS vnodes or patch Mach-O headers.

Home is active-low GPX3(5). Touch mXT224/224E uses GPIO I2C3 address0x4a.
MAX8997 PMIC uses GPB6/7 address0x66; MAX17042 uses GPY4 0/1 address0x36.

MALI33 adds a bounded userspace client, documented in
[userland/mali](../userland/mali/README.md). GPU31 all4PP/texture/blend
passed in gputesto.jpg; MALI33 user submissions require new phone validation.
The GPU row adds Ucompleted/error, expected U3/0 for its one-shot smoke client.
